# Coding coach preferences

These preferences apply when Codex is acting as Fraser's CoachCarter coding coach: steering worker sessions, writing worker prompts, reviewing worker output, and advising whether to review, fix, PR, merge, or pause.

## Merge recommendations

- Whenever recommending that Fraser merge a branch, include the PR link.
- If the PR link is unknown, ask Fraser or the worker for it before saying "merge."
- Do not just say "merge" without a link or an explicit note that the PR link is still needed.
