03 / Controlled pilot

One approved adult learner

Only one verified same-school learner can hold active pilot access. The learner must separately confirm they are 18 or over at checkout. Granting access does not enable purchasing or create a Checkout.

04 / Eligibility

Manual test-booking verification

Review evidence outside the application. Store only the learner-supplied date, time and centre plus this audit decision.

05 / Programmes

Full Curriculum matching

Assign an eligible same-school instructor, record only the recurring availability actually agreed, then set the programme start. Availability is not a reservation or lesson booking.

06 / Refunds

Manual Full Curriculum refund cases

Calculation evidence is immutable. One admin verifies the Stripe fee and calculation; a different admin approves. A named operator then acts in Stripe Dashboard and records only the resulting refund identity and outcome.

07 / Flexible Hours

Purchases, allocation and refunds

Read-only reconciliation uses immutable 30-minute source units. Refunds are performed manually against the original Stripe payment; this page records the resulting evidence and reduces only unused source value.
